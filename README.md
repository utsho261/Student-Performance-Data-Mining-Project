An end-to-end data mining and machine learning study analyzing the key socioeconomic, behavioral, and academic factors influencing student performance.

## 🎯 Objectives
- Conduct Exploratory Data Analysis (EDA) to uncover correlation patterns between study habits, attendance, parental education, and test scores.
- Clean and preprocess raw tabular datasets handling missing values and categorical encoding.
- Build and evaluate predictive classification and regression models to identify students at risk of underperforming.

## 📂 Repository Contents
- `Student_Performance_Data_Mining_Project.ipynb`: Interactive Jupyter Notebook containing data preprocessing, visualizations, and model evaluations.
- `StudentPerformanceFactors.csv`: Feature dataset with social and environmental parameters.
- `StudentsPerformance.csv`: Academic examination scores and demographic data.

## 🛠️ Tools & Libraries
- Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
